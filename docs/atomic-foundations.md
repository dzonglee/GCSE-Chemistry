# Inside an atom: foundational concepts extension

The original atom lesson began with subatomic placement/counts without explicitly teaching the smallest elemental unit or the distinction between element identity and compound composition. This individually researched extension adds those foundations to the existing route. Final browser verification and personal image inspection are complete. Explicit sample delivery is recorded below.

## Content and interaction

The lesson retains its original 24 task identities and positions, including the two original sealed check and delayed-review forms. It adds 22 individually written tasks: two warmups, four refreshers, three guided activities, five practice responses, a five-question check and a three-question delayed review. Total: 46 tasks, including 11 practice responses and three manually reviewed explanations. No extra route is created; the course still has 95 lessons.

| Activity | Chemical purpose |
| --- | --- |
| Represent neutral Na-23 in the existing real 3D atom | Set 11 protons, 12 neutrons and 11 electrons; identify Na using a supplied reference. Editing the model is explicitly a change of representation, not a real chemical conversion. |
| Inspect real H₂O and CO₂ molecular assets | Predict per-molecule atom counts and distinguish water's fixed H:O 2:1 ratio from carbon dioxide's C:O 1:2. Sphere radii/stick lengths are schematic. |
| Inspect joined H₂O atoms and predict a separating change | Distinguish recovering water by physical separation from decomposing it into elements by a chemical reaction. |
| Dedicated element/formula recovery | Compare He atoms with N₂ molecules; separate atom totals from different element types. Wrong work is retained when returning to the original task. |
| New independent examples | Interpret NH₃, a supplied CH₄/CO₂ mixture, lithium's proton number and pure-HCl vaporisation. Written reasoning receives manual comparison, never an automatic examiner mark. |

A supplied first-twenty reference gives atomic numbers, names and exact symbols in a two-column table. It remains available in independent checks as given data; opening it is not treated as a hint. Its 20 identities were independently checked against the actual supplied AQA periodic table. It deliberately omits relative masses rather than confusing model isotope numbers with weighted relative atomic masses. Existing five-column periodic-lesson reference behavior is preserved.

The twenty new automatic references are independently checked in the dedicated unit test. Two new explanations are always manual, including when the reference wording is entered. Direct repeated-meaning aliases cover the same atomic-unit, sodium-symbol, water-state and elemental-molecule reasoning. Different supplied formulas/proton numbers remain separate. Check answers, criteria and model support stay concealed until whole-set submission; original history, form matching and delayed-review scheduling are retained.
