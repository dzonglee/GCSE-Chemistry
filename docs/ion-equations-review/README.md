## Finding and limits

Full molecular construction was **not absent**: original Practice Task27, `ion-tests-v1-p-molecular`, already asks for `CuCl₂(aq) + 2NaOH(aq) → Cu(OH)₂(s) + 2NaCl(aq)` with manual criteria. The 95-task original journey also has charge/state teaching, eight coefficient constructions with species supplied, six dedicated activity modes, 35 original supplied cases and seven manual responses. The confirmed gap is progression into complete-formula construction in guided work, independent forms and delayed retrieval. Those original tasks, native observations and apparatus evidence are preserved.

AQA8462 4.8.3.2 explicitly requires balanced equations for producing insoluble hydroxides. It does **not** explicitly say every answer must be molecular, and the selected paired questions below do not establish that claim. Complete formula equations from precisely named soluble reactants are supporting transfer to the mandatory balanced-equation skill. Naming spectator ions supports interpretation; independent formal ionic-equation writing remains a Higher requirement. Here “molecular” means the complete formula equation, not that ionic salts consist of discrete molecules.

This is Separate Chemistry at both tiers; the new common-tier responses do not require independent Higher-only ionic-equation writing. No Pearson/OCR certification, whole-course completion, grade prediction or supervised practical competence is claimed.

## Before/after design decisions

Before authoring: the interesting thinking is deriving the hydroxide formula from charge, conserving whole formulas, distinguishing precipitate from unchanged dissolved ions, and keeping iron oxidation states distinct. A short free equation response is appropriate; an extra generic coefficient widget would duplicate eight existing constructions. No new 3D/diagram asset is needed. Existing ion apparatus, precipitate observations, fixed-equation activities and original molecular practice stay useful.

After authoring: eight reference equations were independently checked against literal formulas, conserved element totals, aqueous/solid states and spectators. Common coefficient multiples remain acceptable in manual criteria. Calcium precipitation is supplied as a condition, with the reference acknowledging slight solubility. Aluminium is initial precipitation only. No redox/H₂ or sodium-aluminate equation was introduced. Each response asks one equation and spectator names, not an essay. Independent criteria/references appear only after whole-set submission; there is no automatic written examiner mark.

The actual neighbouring Maths source `src/content/course/forming-equations.ts` was read and compared with the reference copy. Its guide supplies equations from angle/perimeter/age contexts and uses a number-line answer; its independent task asks a numerical context response. Six live fonts-ready views at320/390/1280 were personally inspected (guided and independent at each width, own server3300). This supports short prompts, a visible first answer and task-specific input; it does not justify pretending chemical equation writing is a single numerical answer or requiring a Maths number line here. New Chemistry responses use plain textarea input, local Archivo/Atkinson fonts, task-first cards and restrained manual feedback. Native apparatus activities continue to carry practical interpretation.
