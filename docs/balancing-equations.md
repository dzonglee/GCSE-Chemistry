## Before building

**Interesting/interactive?** Manipulate complete-formula coefficients, retain every wrong element count, compare each element independently, and translate supplied word products. Contrast a tempting atom-balanced identity change with the specified reaction. Separate conservation, fractional intermediate ratios and smallest whole-number reporting. Construct complete equations independently, rather than answering only one missing coefficient.

**Assets?** A truthful element ledger; complete formula units for metals/ionic substances rather than isolated salt molecules; molecular amount diagrams and an optional actual 3D methane-combustion collection. Molecules regroup and total molecule number changes while element totals match. The asset depicts amounts before and after, not atom trajectories or a reaction mechanism. Readable 2D amounts remain available without WebGL.

**Generic template?** The Maths balance manipulates equality and shows when a one-sided change loses it. Chemical balancing requires fixed species, coefficient×subscript totals, all-element conservation and ratios. A scale alone could falsely imply that equal total mass proves the correct substances or all element counts.
