## Before building

**Interesting and interactive?** Keep all repeat results visible while selecting a justified exclusion; construct the retained count and mean. Distinguish the endpoints of a range from its width and a supplied half-range uncertainty convention. Move an entire repeat distribution by a calibration offset without shrinking its spread. Compare repeatability within each investigator's set with reproducibility between two sets.

**Assets?** Actual scaled two-dimensional distributions with retained/excluded points, a student's proposed mean marker, range endpoints, a supplied reference line and two-investigator comparisons. These are quantitative diagrams, not particle models; adding atomic 3D geometry would not explain measurement uncertainty. Preserve original values and labels when excluded. Use the same numerical axis when comparing distributions.

**Specific demands and generic template?** Repeats do not automatically remove systematic error or establish accuracy. Excluding the furthest reading solely to obtain a preferred answer is unjustified. Each task must specify which readings belong to its range/mean and any supplied uncertainty convention. Half-range is an estimate of repeat scatter, not proof of the true value or a guaranteed interval for every future observation. Investigation and recorded reasons must accompany removal of an anomalous result.
